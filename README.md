This is my repository where I document my journey through HackerOne's Hacker 101 CTF program!

## How to navigate:
The file structure is as follows
```
This repository
|----CTFs
|    |----Final_Reports
|    |    |----Markdown
|    |    |----PDFs
|    |----Raw_notes
|----Personal_Academic_Notes
```

### CTFs
In the CTFs folder, I organize my documentation into `Final_Reports` where I keep my **official remediation reports** based on my findings, detailing the vulnerabilities found and how to guard against them, and `Raw_notes` where I detail my exact unfiltered process of finding the vulnerabilities and documenting what I tried regardless of whether or not a vulnerability was found to yield a flag.

In `Final_Reports` there is the option to view the remediation report as a Markdown file or PDF, this is done for compatibility and formatting purposes, the content of the reports remain the same regardless of which format is viewed.

### Personal_Academic_Notes
This is where I store my own personal notes as I go through the free lessons that HackerOne provides on their platform. This is purely personal and serves no purpose for official documentation of my progress through the CTF program.
